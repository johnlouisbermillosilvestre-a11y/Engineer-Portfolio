# John Louis — Computer Engineering Portfolio

A clean, interactive portfolio built with **TypeScript + Vite + HTML + CSS**.

## Included
- Responsive single-page portfolio
- Smooth navigation
- Scroll reveal animations
- Mobile navigation menu
- Project showcase
- BSCpE coursework section
- Skills and engineering toolkit
- Copy-email interaction
- Back-to-top button
- Dark green engineering aesthetic

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for deployment

```bash
npm run build
npm run preview
```

## Customize
Edit `src/main.ts` to change your:
- school
- projects
- course list
- skills
- email
- profile information

Edit `src/style.css` to change the visual theme.
